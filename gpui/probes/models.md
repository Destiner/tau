# Models · native picker probe

Run the persistent window with `cargo run --manifest-path gpui/Cargo.toml --bin models-probe` (add `--dark` for dark appearance). Capture isolated Metal frames with `--capture /tmp/tau-models-light` and `--dark --capture /tmp/tau-models-dark`; each directory contains PNGs and `checks.json`. `--list-checks` lists the deterministic sequence.

The picker uses Base `Popup`, `Button`, and two real `InputState` editors: search and retained composer draft. The catalogue has 36 finite synthetic models in three provider groups; Atlas Model 08 is disabled. The selected model is shown on the trigger and marked in the list. Opening positions the selected row in the scroll viewport and focuses search. The search filters by label or synthetic id. Up/Down/Home/End and contained Tab/Shift-Tab navigate enabled filtered rows, reveal the cursor through a real `ScrollHandle`, Enter selects, Escape cancels. Search-only key bindings leave composer editing shortcuts alone. A click outside dismisses without selecting. Closing always returns focus to the composer (not the pointer-only model trigger). “Fail Next” rejects one choice, retains the old model and draft, and presents a local retryable notice.

The sequence verifies actual input text, focus handles, rendered surface/empty/notice/option visibility, scroll offset after wheel, selected-row bounds against the viewport after navigation, and selection/attempt effects. It covers disabled click and disabled-only filtered Enter, keyboard focus containment, cancellation, filtered empty/Enter, successful Enter, failure rollback, outside dismissal and retry. Checks are run in both appearances from independent windows. No Pi/SDK calls, model discovery, persistence, screen reader audit, or Vue integration are implied by this isolated fixture.

# Native composer probe

Run `cargo run --manifest-path gpui/Cargo.toml --bin composer-probe -- --capture /tmp/tau-composer-light` (add `--dark` for dark mode). `--list-checks` lists checkpoints. The shared runner accepts `--fault hide-content|skip-input` in capture mode.

The retained Base `TextareaState` owns editing; Enter submits a nonempty draft, Shift+Enter inserts a newline. A synthetic `/help` completion can be accepted by Enter or pointer; Escape dismisses it without clearing the draft or reopening it as typing continues. Clearing the slash prefix allows it to open again. Send and Stop simulate submission and cancellation; while busy, Enter cannot submit a second time and an unsent draft survives Stop. Model and Context toggle without replacing the editor or taking focus from it. Long and tall drafts exercise shaped wrap and the eight-row height cap. Read older and Latest operate on a measured transcript. Resize viewport inserts/removes a 100px panel, **not** an OS resize.

Each check writes a 2x Metal PNG and observations to `checks.json`. Checks inspect the actual Base draft/focus, submission count, completion insertion, measured editor min/growth/max heights, measured position of a reader item before/after viewport height change, and the last-row-to-viewport-bottom gap while following. The unbroken fixture tests growth and containment of the shell; it does not pixel-prove every glyph stays within the shell. No Pi runtime, persistence, remote completion, real context/model change, OS window resize, IME, clipboard, or large-session responsiveness is established.
